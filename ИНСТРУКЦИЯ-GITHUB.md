# multiplayerSHOW на GitHub: установка и обновление

Код программы лежит в открытом репозитории на GitHub. Ваши данные (песни, Библии, медиа, настройки) туда **не попадают**: они хранятся в `%APPDATA%\church-presenter` и в вашей папке «Репозиторий».

## Один раз на этом (рабочем) компьютере

1. Установить Git (в cmd):
   ```
   winget install --id Git.Git -e
   ```
   После установки закройте и откройте cmd заново.
2. Зарегистрироваться на github.com. Нажать «+» → **New repository**: имя `multiplayerSHOW`, **Public**, без README → **Create repository**. Скопировать адрес вида `https://github.com/ваше-имя/multiplayerSHOW.git`.
3. Двойной щелчок по **`подключить-github.cmd`** в папке программы и вставить адрес. В первый раз Git откроет окно входа в GitHub, войдите.
4. Через 5–10 минут на странице репозитория, в разделе **Releases**, появится `multiplayerSHOW-Setup-0.1.0.exe`. Ход сборки виден во вкладке **Actions**.

## Установка на другом компьютере

1. Открыть `https://github.com/ваше-имя/multiplayerSHOW/releases`, скачать `multiplayerSHOW-Setup-….exe`, запустить.
2. Windows может написать «Windows защитил ваш компьютер»: нажмите **Подробнее** → **Выполнить в любом случае**. Так бывает с программами без платной цифровой подписи.
3. Перенести данные: скопировать папку репозитория (флешка, облако). В программе: **Настройки → Репозиторий → «Выбрать папку…»** и указать её. Программа предложит восстановить.

> Если на компьютере включён **«Интеллектуальный контроль приложений»** (Smart App Control: Безопасность Windows → Управление приложениями/браузером), он не даст запустить установщик без подписи. Его можно выключить только там же, вручную, но включить обратно потом нельзя без переустановки Windows. На этом рабочем компьютере он включён.

## Выпустить новую версию

1. Делаете и проверяете правки здесь (`npm start`).
2. Двойной щелчок по **`выпустить.cmd`** и пара слов о том, что изменилось. Номер версии вырастет сам (0.1.0 → 0.1.1).
3. Через 5–10 минут новая версия появится в Releases.

## Обновить на другом компьютере

Программа сама проверяет новую версию через полминуты после запуска, если стоит галочка «Проверять обновления при запуске». Новая версия скачивается в фоне и ставится, **когда вы закроете программу**. Посреди служения ничего не перезапускается.
Вручную: **Настройки → Обновление программы → «Проверить обновления»**, потом «Перезапустить и обновить».
