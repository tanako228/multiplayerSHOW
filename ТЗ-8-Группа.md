# ТЗ-8. Приложение для группы (телефоны и планшеты музыкантов)

Одно веб-приложение (PWA) для музыкантов, вокалистов, техников: песни, текущий слайд, пометки, офлайн.
Ставится на экран «Домой» (iOS и Android). APK — позже, обёрткой над той же PWA.
Утверждено владельцем 09.11.2026. Делается по этапам, после каждого — проверка, инструкция, отдельный коммит.

## Как встроено в программу

- **Один сервер.** Тот же обработчик, что у пульта (`rmHandle` в main.js). Адреса: `/r/<ключ>` — старый пульт,
  `/app/…` — приложение группы, `/api/v1/…` — данные, `/ws` — WebSocket (этап 2).
  http — порт 8090 (как раньше, для пульта и запасного входа по IP), https — постоянный порт (по умолчанию 443).
- **`teamsrv.js`** (главный процесс, как `ndi.js`, `cast.js`): адрес-домен, сертификат, DNS-провайдеры, проверка адреса,
  дальше — вход, устройства, синхронизация песен. Работает и без Electron (проверка в Node).
- **`team.js`** (окно оператора, после `remote.js`): окно «Группа» (кнопка в верхней строке).
- **`app/`** — само приложение для телефона (исключение из «всё в корне»): index.html, app.js, sw.js, манифест, `vendor/`
  (MiniSearch, idb, perfect-freehand — копии файлов, без CDN), свой шрифт (строки ложатся одинаково на всех телефонах).
- Данные группы — не в `lib` (иначе Ctrl+Z «вернул» бы отозванный доступ): `%APPDATA%\church-presenter\team.json`
  (настройки адреса; позже профили, устройства), `team-log.jsonl` (журнал), `tls\` (ключи и сертификат).
  Токен DNS-провайдера — зашифрован Windows (`safeStorage`), в окно оператора не уходит.
- npm (чистый JS, без компиляции): `acme-client` (этап 0), `ws` (этап 2), `bcryptjs` (этап 6).

## Адрес и HTTPS (этап 0)

- Домен (бесплатный поддомен deSEC `*.dedyn.io` или Duck DNS `*.duckdns.org`; позже свой домен на deSEC — только настройки)
  указывает на **локальный** IP компьютера. Программа сама меняет A-запись при смене IP (раз в минуту сверяет).
- Сертификат Let's Encrypt через DNS-01: программа ставит TXT `_acme-challenge.<домен>`, ждёт его на серверах имён
  провайдера, получает сертификат. Продление само, когда осталось меньше 30 дней (проверка каждые 6 ч).
- Порт и домен после установки приложения на телефоны **не менять**: у телефона данные хранятся «на адрес»,
  новый адрес = пустое приложение (перенос — экспорт/импорт, этап 7).
- DNS rebinding: кнопка «Проверить адрес» сравнивает ответ публичного DNS (1.1.1.1, 8.8.8.8) и DNS этого компьютера
  (обычно роутер). Как обойти — `ИНСТРУКЦИЯ-ГРУППА.md`.

## Песни и аккорды в базе (проверено 09.11.2026)

- Песня — `item.song = { text, arrangements, arr, number?, ccli?, genre?, chords? }`, слайды собирает `Songs.build`,
  id слайда держится по месту (часть + повтор + номер в части) — это стабильный id для пометок.
- Аккорды — отдельное поле `song.chords` («Аккорды для сцены»): тот же текст с аккордами `[Am]Слава [G]Богу`
  или строкой над словами; разбор — stage.js (`stChordSheet`, `stChordsFor`). В базе владельца из 3175 песен
  аккордов нет ни у одной; тональности, темпа и размера у песен нет. Плейлисты — без даты и тональности.

## Этапы

0. Сервер и HTTPS: домен, сертификат, A-запись, проверка адреса, брандмауэр, окно «Группа» → «Адрес».
1. Подключение, доступ, библиотека, офлайн: QR → «Ожидают подтверждения» → токен устройства; права — на сервере;
   окно «Группа»: кто в сети, ожидают, отключить, отозвать, журнал; профили без паролей. Загрузка базы порциями
   (прогресс, докачка, gzip), дальше — «изменения с номера N» (`/api/v1/songs/changes?since=N`; главный процесс
   ведёт отпечаток и номер изменения каждой песни из `lib:save`, помнит удалённые). IndexedDB, Service Worker,
   `storage.persist()`, индикатор связи, дата синхронизации, число песен, поиск MiniSearch (ё=е, опечатки).
2. Реальное время и сетлист: WebSocket, протокол v1 (вход, сессия, песня изменилась, библиотека, сетлист, ping 15 с,
   переподключение 1→2→4…30 с); «Следовать / Листать самому»; Библия и свои слайды — текстом с текущим слайдом;
   сетлист = плейлист с пометкой «для группы», датой и тональностью строки; право «управлять презентацией».
3. Пометки и заметки: перо/палец, нажим, цвета, маркер, ластик, отмена/повтор, «только стилус»; заметки к песне;
   векторы x/y 0–1, привязка к песне, слайду и строке текста.
4. Музыкант / Вокалист: аккорды над строками, транспонирование, капо (запоминается по песне); поля «Тональность»,
   «Темп», «Размер» в окне песни; общий `chords.js` для сцены и телефона.
5. «Моя версия»: редактор на телефоне, Оригинал / Моя версия, подписать, выделить, замазать, подчеркнуть;
   «Оригинал изменился» — различия, оставить или сбросить.
6. Команда и полный доступ: сообщения группе (Лидер, Звук), метроном по времени сервера, пароли (bcrypt),
   режимы входа (QR / QR + пароль / имя и пароль), временная блокировка, полный журнал.
7. Экспорт/импорт JSON, установка (Android — кнопка, iPhone — подсказка), первый запуск: роль и загрузка. APK — позже.
