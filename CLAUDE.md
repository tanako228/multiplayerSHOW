# multiplayerSHOW (MP Show)

Свободная альтернатива ProPresenter для церкви: песни, Библия, медиа, PowerPoint, музыка, вывод на несколько экранов. Windows, MIT.
Стек: Electron 33, чистый JS/HTML/CSS — без сборщика и фреймворков. Владелец не программист: отвечать по-русски, просто, команды для cmd.
Подробное описание всех модулей и решений — `ПОДРОБНО.md` (читать перед правкой незнакомого места).

## Структура (всё в корне)
- `main.js` — главный процесс: окна, IPC, файлы, PowerPoint→PNG, Библии, `library.json`, окна выходов экранов (`syncScreens`). `ndi.js` — NDI приём/отправка (koffi). `cast.js` — AirPlay/Miracast. `preload.js` — единственный мост `window.api`.
- `index.html` — окно оператора; скрипты строго по порядку (общие глобальные функции): icons → iconlib → scene → compose → bible → slides → themes → renderer → playlist → songs → tools → music → sources → layers → themeeditor → quick → macros → screens → audioeditor → stage → qr → remote → splash.
- `scene.js` — отрисовка слайдов и слоёв. `compose.js` — экраны и экранные сцены (общая для вывода и оператора).
- `renderer.js` — настройки, слои вывода, вкладки, горячие клавиши (`ACTIONS`). `playlist.js` — плейлисты/библиотеки, лента, отмена (`HIST_KEYS`).
- Вкладки: `bible.js`, `music.js`; вкладка «Редактор ▾» (меню `edMenu`) — `themeeditor.js` (редактор тем), `screens.js` (редактор сцен: экраны, сцены-выходы, пресеты сцен = макеты, `tab = 'scenes'`), `macros.js` (редактор макросов), `audioeditor.js` (аудиоредактор, `tab = 'audio'`: волна, обрезка, скорость/тон с «Сохранить тон» — WSOLA, встроенные плагины `AE_FX`; сохраняет новым WAV в `media/`, исходник не трогает); `songs.js`, `sources.js`, `layers.js`, `quick.js`, `tools.js` (медиапул, рисование, пресеты).
- `remote.js` + `phone.html` + `qr.js` + `thumb.html/js` — пульт с телефона: доступ к одной презентации по QR-коду (сервер `rmHandle` в main.js, `cp.remote`).
- `stage.js` — сценический экран (Stage Display): данные инфоблоков (`stSend`), таймеры, сообщение, «только на сцену», панель «Сцена» под предпросмотром, ноды макросов.
- `output.html/js` — окно вывода = один экран (`?screen=id`). `editor.html/js` — окно «Картинка» (правка фото); слайды правятся в редакторе тем (`slide.look`, `openSlideLook`), старого редактора слайдов нет. `brand/` — логотипы, иконка (не перерисовывать).

## Команды
- `npm install`, `npm start`. Сборки и тестов нет.
- Проверка: `node --check <файл>`; интерфейс — index.html через локальный http-сервер с заглушкой `window.api`; медиа/звук — только в Electron.
- Electron не распаковался (Node 26): распаковать `%LOCALAPPDATA%\electron\Cache\…\electron-v33.*.zip` в `node_modules\electron\dist` + `path.txt` с `electron.exe`.

## Выпуск и обновление
- Открытый GitHub. `выпустить.cmd` → `npm version patch` + push метки `v*` → `.github/workflows/release.yml` собирает NSIS-установщик (electron-builder, настройки в `package.json` → `build`) и кладёт в Releases. Локально установщик не собрать: на этом ПК Smart App Control блокирует неподписанный exe.
- Обновление — `electron-updater` в main.js (`update:*`), только в установленной программе; ставится при закрытии или кнопкой. Инструкция — `ИНСТРУКЦИЯ-GITHUB.md`.

## Данные (не терять!)
- `%APPDATA%\church-presenter`: `library.json` (items, libraries, playlists, themes, themesLive, macros, screens, scenes, timers, verseSplits…), `bibles/`, `fonts/`, `images/`, `media/`, `slides/`, `thumbs/` (кэш).
- `localStorage`: `cp.settings` и др. Меняешь формат — добавь перенос старых данных (как `Slides.migrate`).
- Запасная копия всех `cp.*` — `settings-backup.json` (preload.js пишет раз в 5 с и при закрытии; пропало хранилище — возвращает при запуске). Вторая копия программы не запускается (`requestSingleInstanceLock`) — две копии стирали localStorage.
- Имя папки данных и метки `app: 'church-presenter'` не менять — по ним узнаются старые файлы.
- Репозиторий (Настройки → Репозиторий): папка владельца, куда программа сама пишет все данные (`REPO_PARTS` в main.js, `repoTouch` в tools.js). Новый ключ `lib`/настроек/`cp.*` попадает туда сам; новую часть — строкой в `REPO_PARTS` и `REPO_NAMES`.

## Решения и правила
- Новый канал окно↔main: `ipcMain.handle` в main.js + метод в preload.js.
- Вывод — слои (Media Layers) снизу вверх: Источники → Медиа → Презентации (`LAYER_KINDS`, `present`, `clearLayer`). Экраны (`lib.screens`) показывают программу (слои по маске); правка макета — черновик до «Применить».
- Экран (`lib.screens`) = программа: выходы, слои, своя тема для текста, «Прозрачный фон» (`s.alpha`). Сцена (`lib.scenes`) = только выход: разрешение, фон (цвет/`'transparent'`), выходы (`sc.on`), альфа-канал, частота и выбранный макет `sc.layout`. Макеты — «Пресеты сцен» (`lib.scenePresets`), правятся только там (макет внутрь сцены не возвращать). Сценический экран — просто сцена с выходом (`kind: 'stage'` нет; старое, в том числе макет внутри сцены, переносит `scMigrate` — макет получает id сцены). Отрисовка одна — compose.js. Таймеры, сообщения, «только на сцену» экраны зрителей не трогают.
- Всё, что меняет `lib` и зовёт `saveLib`, отменяется Ctrl+Z само — новых путей отмены не писать; удаление без `confirm`, со строкой «Ctrl+Z — вернуть».
- Сообщения: ошибки и долгие загрузки — `showNotice`; остальное — `flashStatus`. Ввод имени — `askName()`, меню — `showMenu()`.
- Горячие клавиши — по `e.code` (русская раскладка). Книги Библии — по `canon`.
- Цвета интерфейса — CSS-переменные (`--ink --panel --field --line --text --muted --live --warn`). Иконки — `data-icon` + строка в `icons.js` (стандарт Multi Play), без эмодзи; подпись кнопки с иконкой — `Icons.label`. Иконку на выбор пользователю (макросы) — `iconlib.js`: `IconLib.pick/el`, значок `'знак:цвет'` или data:-картинка; новые знаки — туда же, по темам. Выбор презентации в ноде макроса — параметр 	: 'item' (поиск + библиотека/плейлист). Инструкция по макросам — ИНСТРУКЦИЯ-МАКРОСЫ.md (и окно «?» в редакторе): меняешь макросы — поправь.
- Ползунки: двойной щелчок — значение по умолчанию (общий обработчик в icons.js). Новому ползунку — `data-def` (или атрибут `value` в HTML); не сбрасывать — `data-nodef`.
- Текст на слайдах подгоняется сам (ResizeObserver). Панели — без анимации, ширина через `.splitter`.
- Комментарии по-русски, коротко; без лишних абстракций; интерфейс на русском.
- Решения владельца, которые нельзя откатывать, — в `ПОДРОБНО.md` (помечены «не возвращать»).
- Создавать новое — только в библиотеке; в плейлист — только перетащить готовое (библиотека, Библия, медиапул): `plNoCreate()`, `addItems(…, how)`.
- Переходы — одна таблица `TRD` в scene.js (`Scene.TRANS`); свой переход `item.trans`/`slide.trans`, авто-переключение `item.auto`/`slide.autoSec` (окно `openFx`).
- Блоки под предпросмотром — `aside > .as-blk[data-blk]`, порядок `settings.asideOrder`; экран в предпросмотре — `settings.prevScreen`.

## Библия (renderer.js, раздел «Слайд Библии»)
- Окно «Библия» (кнопка, бывшие «Переводы»): до 4 переводов на экране — `settings.bSlots = [{ id, text, ref }]`, строка 0 — открытый перевод (`id: ''`). `text`/`ref` — только имя текстового окна шаблона (`Scene.textLabels`) или `''` — «Нет» (владелец: «только привязка к окнам»; «Авто» в окне не предлагать). Старое `'auto'` переводится в окно с bind content/ref (`slotsToBoxes`); в сцене `'auto'` осталось для темы без шаблона. Тема и шаблон Библии выбираются тут же (`lib.themeFor.bible`, `lib.tplFor.bible`); окна — из черновика темы. Оформление берётся из окна темы. Старые `bible2Id/b2Text/bRef1/bRef2…` переносятся в `bSlots`.
- Слайд: `bibleData` → `trs` (все переводы, порядок как `bSlots`), в сцене — `bibleBoxes/bibleInBox` (scene.js). Несколько переводов в одном окне или тема без окон — колонками.
- Длинные стихи — только показ, стих в файле целый: `verseParts` (настройки `vSplit vMinFont vMaxChars vMaxParts`), `splitSense` — почти равные части (2 — половинки, 3 — трети), разрез у знака препинания рядом с серединой, иначе между словами. Ручное деление — `lib.verseSplits` (Ctrl+Z работает).
- «＋» у поля «Место» — дополнительные стихи заранее (`bSet`, полоска `bsetBar`), в плейлисте `extra: true`.
- Закладки (`cp.bookmarks`): выделение `bmPick` (Ctrl/Shift+щелчок, Ctrl+A при фокусе в `#bmList`), перетаскивание — `x-cp-bible` с `{ groups }`, `dropBible` делает по презентации на закладку.
- Инструкция для владельца — `ИНСТРУКЦИЯ-БИБЛИЯ.md`: меняешь Библию в интерфейсе — поправь и её.
- Выбор книги/главы/перевода не сбрасывает прокрутку (`renderNav` хранит scrollTop) — не ломать.

## Чего НЕ делать
- Не подключать внешние скрипты/CDN (CSP: `'self'`, `file:`, `data:`). Не включать `nodeIntegration`.
- Не использовать `\b` в регулярках рядом с кириллицей; не использовать `window.prompt`.
- Не удалять и не перезаписывать данные в `%APPDATA%\church-presenter`; не трогать файлы пользователя (правки — копией в `images/`).
- Библию не заменять: новый перевод — новый файл с новым id.
- Не делать LUT (.cube) — владелец отказался.
- Не возвращать: «Отдельные файлы», дерево/избранное в «Источниках», свой порог перетаскивания 8 px, просмотр пункта по щелчку вместо открытия.
