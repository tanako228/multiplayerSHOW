# multiplayerSHOW

Открытая программа для показа песен, Библии, фото, видео и презентаций на экранах в церкви. Задумана как свободная альтернатива ProPresenter. Работает в Windows. Лицензия: MIT.

## Установка

Скачайте `multiplayerSHOW-Setup-….exe` из [Releases](https://github.com/tanako228/multiplayerSHOW/releases) и запустите его.

Windows может написать «Windows защитил ваш компьютер» — нажмите **Подробнее** → **Выполнить в любом случае**. Так бывает с программами без платной цифровой подписи. Если включён «Интеллектуальный контроль приложений» (Smart App Control), он не даст запустить установщик без подписи.

**Обновление.** Программа сама проверяет новую версию через полминуты после запуска (галочка «Проверять обновления при запуске»). Новая версия скачивается в фоне и ставится, **когда вы закроете программу** — посреди служения ничего не перезапускается. Вручную: **Настройки → Обновление программы → «Проверить обновления»**.

**Перенос на другой компьютер.** Включите **Настройки → Репозиторий** и выберите папку — программа будет сама копировать туда песни, Библии, медиа и настройки. На новом компьютере скопируйте эту папку (флешка, облако) и укажите её там же: **Настройки → Репозиторий → «Выбрать папку…»** — программа предложит всё восстановить.

Из исходников: установите Node.js (LTS), откройте папку проекта в командной строке (cmd) и выполните:

```
npm install
npm start
```

Если Electron не скачался, выполните `node node_modules\electron\install.js`.

## Что умеет

**Показ**
- Песни с частями (куплет, припев, мост) и аранжировками: порядок частей задаётся для каждой песни отдельно. Есть аккорды, тональность, транспонирование и капо.
- Библия: переводы в форматах Zefania/OSIS XML, JSON и текст; ввод места (`Ин 3:16`, `1 Кор 13:4-7`, `Пс 22`) и поиск по словам. На экране до 4 переводов сразу, длинные стихи делятся на части, нужные стихи можно подготовить заранее и сохранить в закладки.
- Фото, SVG, видео, презентации PowerPoint (pptx, ppt, ppsx, odp — превращаются в картинки слайдов через установленный Microsoft PowerPoint).
- Свои слайды с текстом, темы и шаблоны оформления, переходы и автоматическое перелистывание.
- Источники: камеры, захват окна или экрана, NDI, приём экрана с телефона по AirPlay и Miracast.
- Слои вывода (Источники → Медиа → Презентации): каждый слой включается и очищается отдельно.

**Экраны**
- Несколько экранов и выходов: мониторы, окно, NDI-выход, прозрачный фон для эфира.
- Сценический экран для ведущего и музыкантов: следующий слайд, часы, таймеры, сообщения, заметки, аккорды.
- Таймеры и обратный отсчёт.

**Подготовка служения**
- Библиотеки и плейлисты, медиапул; отмена любого действия по Ctrl+Z.
- Музыкальный плеер (играет только у оператора, на экран не выходит) и аудиоредактор: обрезка, скорость, тон.
- Редактор тем, редактор сцен и макетов, редактор картинок.
- Макросы: одной кнопкой выполнить сразу несколько действий.
- Проверка перед служением (Настройки → «Показ и звук»: все видео на месте, мониторы подключены, шрифты есть, Библия загружена). Значок «Плашки» сверху: готовые плашки (имя проповедника, объявление, Wi‑Fi, пожертвования), бегущая строка и презентации, которым выбран слой «Плашки».
- Библия по голосу: программа слушает проповедника и, когда он называет место («Иоанна 3:16»), предлагает его одной кнопкой. Распознавание работает без интернета (модель языка скачивается один раз, около 45 МБ).
- Перенос песен (кнопка «＋») из OpenLP, EasyWorship, ProPresenter (.pro, .pro6) и SongSelect (CCLI, .usr и .txt).

**Телефоны**
- Пульт с телефона по QR-коду: листать одну презентацию или править её текст.
- Приложение для группы (музыкантов) на телефонах: песни и аккорды, что сейчас на экране, сетлист, «Моя версия» песни, пометки стилусом, сообщения, общий метроном. Работает и без интернета.

**Прочее**
- Языки интерфейса: русский, английский, эстонский.
- Горячие клавиши: стрелки, PageUp/PageDown и пробел листают; Esc или B очищает экран.
- Все данные можно автоматически копировать в свою папку (Настройки → Репозиторий).

## Что нужно для отдельных функций

- Презентации PowerPoint — установленный Microsoft PowerPoint.
- NDI (приём и выход) — бесплатные NDI Tools (NDI Runtime).
- AirPlay — `uxplay.exe` и Bonjour; Miracast — приложение Windows «Беспроводной дисплей».
- Пульт и приложение для группы — телефон в той же сети; программа сама предложит разрешить доступ в брандмауэре.

## Где хранятся данные

`%APPDATA%\church-presenter`: библиотека (`library.json`), Библии, шрифты, картинки, медиа, слайды презентаций, данные группы. Не удаляйте эту папку — в ней все песни и настройки.

## Для разработчиков

Electron 33, чистый JavaScript/HTML/CSS без сборщика и фреймворков. Устройство программы и принятые решения описаны в [ПОДРОБНО.md](ПОДРОБНО.md). Проверка файла: `node --check <файл>`. Установщик собирается на GitHub (`.github/workflows/release.yml`), когда отправляется метка версии `v*`.
