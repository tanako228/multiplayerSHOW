# multiplayerSHOW

Открытая программа для показа фото, видео, презентаций и Библии на экранах в церкви. Задумана как свободная альтернатива ProPresenter. Лицензия: MIT.

## Запуск (Windows)

Готовая сборка: распакуйте архив и откройте `ChurchPresenter.exe`.

Из исходников: установите Node.js (LTS), откройте папку проекта в командной строке (cmd) и выполните `npm install`, затем `npm start`. Если Electron не скачался, выполните `node node_modules\electron\install.js`.

## Как пользоваться

- «Включить вывод» открывает чёрное окно на выбранном мониторе. Справа всегда виден предпросмотр того, что на экране.
- Вкладка «Экран»: фото, SVG, видео и презентации. Клик по элементу показывает его. Стрелки, PageUp/PageDown и пробел листают, Esc или B очищают экран.
- Презентации (pptx, ppt, ppsx, odp) превращаются в картинки слайдов через Microsoft PowerPoint (нужен установленный PowerPoint). Готовые слайды сохраняются.
- Вкладка «Музыка»: плеер играет из окна оператора и не мешает экрану.
- Вкладка «Библия»: добавьте перевод (XML Zefania/OSIS и похожие, JSON, текстовые файлы). Введите место (`Ин 3:16`, `1 Кор 13:4-7`, `Пс 22`) или ищите по словам. Клик по стиху показывает его, Shift+клик показывает несколько стихов подряд. Стрелки листают стихи. Несколько переводов, дополнительные стихи и деление длинных стихов — в [ИНСТРУКЦИЯ-БИБЛИЯ.md](ИНСТРУКЦИЯ-БИБЛИЯ.md).
- Справа настраиваются эффект и длительность перехода, разрешение вывода (вплоть до 8K или своё), размер картинки, звук и повтор видео, качество слайдов и оформление текста Библии. Настройки запоминаются.

## Структура

- `main.js` — главный процесс: окна, мониторы, импорт презентаций, хранение Библий
- `preload.js` — безопасный мост между окнами и главным процессом
- `index.html`, `renderer.js` — окно оператора
- `scene.js` — общая «сцена» (картинка, видео, текст, переходы) для вывода и предпросмотра
- `bible.js` — разбор файлов Библии, ссылки на места, поиск по словам
- `output.html`, `output.js` — окно на внешнем мониторе
